# ChessLab for Windows 11

Исходный проект шахматного приложения ChessLab. Архив исходников и автоматическая Windows-сборка будут добавлены отдельными файлами/коммитами.

Приложение использует python-chess для соблюдения правил шахмат и Stockfish как локальный UCI-движок. Сборка Windows выполняется GitHub Actions.
